# Math Data

**Math Data** is an interactive web-based mathematics platform designed to assist students and teachers with mathematical calculations, problem solving, and learning.

The project provides a collection of independent mathematical tools and educational sections through a simple and user-friendly web interface.

## ✨ Features

Math Data includes several mathematical tools and learning sections:

### 🧮 Calculations

* Mathematical calculator
* Square roots and powers
* Average calculation for any number of values
* Percentage and exam score calculation

### 📐 Geometry

* Area and geometric calculations
* Predefined geometric shapes
* Calculations based on dimensions such as length, width, radius, and height

### 📊 Equations

* First-degree equations
* Quadratic equations
* Systems of two equations with two unknowns

### 🔢 Mathematical Identities

The project includes tools for working with common algebraic identities, including:

* Five common identities
* Square of a binomial
* Cube of a binomial
* Conjugate expressions
* Common-term identities
* Additional algebraic calculation tools

### 📚 Learning Materials

The website also contains separate educational sections and explanations to support mathematical learning.

## 🎯 Purpose

The main goal of Math Data is to provide students and teachers with an accessible collection of mathematical tools in a single web-based platform.

Students can use the different sections to practice mathematical concepts and perform calculations, while teachers can use the available questions, explanations, and tools as supplementary educational resources.

## 🛠️ Technologies

The project was developed using:

* **HTML**
* **CSS**
* **JavaScript**

The application runs directly in a web browser without requiring a separate backend.

## 📈 Development

The project was originally developed as a personal project during February and was progressively expanded and improved throughout different stages of development.

New sections and mathematical tools were added during the development process, making the project more comprehensive over time.

The project contains **4,400+ lines of code** across its different sections.

## 🖥️ How to Run

No installation or build process is required.

1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Start using the mathematical tools.

## 📁 Project Structure

The project is organized into multiple HTML, CSS, JavaScript, and image resources, with different sections of the website handling specific mathematical functions and content.
